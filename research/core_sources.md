# Core sources (canon-minimum)

Each entry: citation + what it supports.

1) Yann LeCun, "A Path Towards Autonomous Machine Intelligence" (2022)
- Supports: autonomy framing: predictive world models + planning; JEPA motivation.

2) Assran et al., "I-JEPA: Self-Supervised Learning from Images with a Joint-Embedding Predictive Architecture" (arXiv:2301.08243, 2023)
- Supports: representation-space prediction yields strong visual representations without generative pixel modeling.

3) Ha & Schmidhuber, "World Models" (2018)
- Supports: latent dynamics + imagined rollouts; policy training inside learned model.

4) Schrittwieser et al., "MuZero" (2019)
- Supports: planning with learned model predicting planning-relevant quantities.

5) Hafner et al., "DreamerV3" (2023)
- Supports: scalable world-model RL across tasks via imagination.

6) Jumper et al., "Highly accurate protein structure prediction with AlphaFold" (Nature, 2021)
- Supports: constraint-driven generalization in a strict scientific domain; usefulness without AGI claims.

7) METR (public evaluation outputs)
- Supports: external evaluation posture; sanity checks vs self-reported claims.

8) Epoch AI (benchmark aggregation and analyses)
- Supports: independent aggregation of trends; cross-checks on reported progress.

Rule:
Add sources only if they change a decision rule or define a core concept.
