# Migration history

This document records provenance for the repository's change in active framing. It does not introduce a separate contribution claim and does not validate either the historical or current project scientifically.

## Old active framing — retired

The following historical framing is retired:

* LLM-centric versus world-model architecture selection;
* world-model + planning and general hybrid closed-loop architecture framing;
* JEPA and AGI framing;
* historical P1, P2, and P3 claims;
* the old prototype as scientific evidence;
* the claimed approximately 70 ms crossover;
* automatic fallback to unverified execution under time pressure.

Historical Git commits are retained for provenance. They show how the repository changed, but they are not part of the active scientific claim.

The historical latency scenario was not a valid reproducible basis for its old quantitative claim. The approximately 70 ms crossover claim is withdrawn. The old code is not being repaired merely to restore evidence for a withdrawn claim.

Historical documents and prototype files may remain in Git history or clearly marked historical locations. Their presence does not make them active methods, evidence, or release claims.

The old architecture-selection surface did not merely receive a new name. Repository audit found that material parts of its claimed evidence—including the latency scenario and approximately 70 ms crossover—were not reproducible or did not support the stated hypothesis. The project therefore retired those claims and narrowed to the surviving testable question concerning verifier evidence independence and joint dangerous-error estimation. This does not imply that every earlier engineering concern was false; it distinguishes the retired evidence claims from the narrower current scientific object.

## New active framing

**Audit the Verifier**

**When agreement is not independent evidence**

The active GitHub repository slug is `audit-the-verifier`. Historical references to `llm-worldmodels-hybrid-decision-frame` remain where they identify earlier repository provenance.

The project narrowed factually through the following sequence:

```text
architecture choice
→ evidence independence
→ verifier authority
→ joint dangerous-error estimation
→ bounded synthetic audit experiment
→ development-terminal C-03 outcome
```

The active repository studies finite-population risk estimation inside a confident primary-model/verifier agreement region under a fixed oracle budget. Its C-03 development execution terminated at the prospective structural-representation gate with exact classification `INCONCLUSIVE_BY_DEGENERACY`.

No confirmatory preregistration or confirmatory experiment occurred. The migration does not convert the old prototype into evidence, validate the current method in a real domain, or authorize a scientific rerun.

The public contribution and non-claim boundary is stated only in the root [README](README.md). This migration note records history and provenance without strengthening that positioning.
